In OBS:
  1. Add a Browser source and paste the address.
  2. Set width 1920 and height 1080.
  3. Tick Control audio via OBS so the music goes into the recording or stream.

To record without OBS, open it in a new window, go full screen (F11, or Ctrl+Cmd+F on a Mac) and click once if it asks to start the sound.
